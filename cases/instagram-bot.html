Telegram-ботAIPython

Telegram-бот для генерации контента с оплатой через Stars

Задача

Избавить владельцев аккаунтов в соцсетях от рутины написания постов, описаний и хэштегов - и сделать это в виде продукта, который сам зарабатывает через платные подписки.

Решение

Telegram-бот, который по запросу пользователя генерирует тексты постов через LLM (Groq API), поддерживает пакетную генерацию нескольких постов за раз, ведёт учёт лимитов по тарифам (бесплатный/Premium/Pro) и принимает оплату через встроенные Telegram Stars.

  • Генерация постов, описаний и хэштегов по теме от пользователя
  • Пакетная генерация нескольких постов за один запрос
  • Три тарифа с разными дневными лимитами, оплата через Telegram Stars
  • Экспорт сгенерированного контента
  • Админ-панель: мониторинг использования API, уведомления об ошибках, контроль дневного лимита LLM-провайдера
  • Обработка ошибок с повторной попыткой и понятными сообщениями пользователю

Результат

Рабочий MVP с полным циклом документации для запуска: быстрый деплой на сервер (systemd), скрипты бэкапа и healthcheck, расчёт экономики (стоимость API-запросов против цены подписки).

Стек

Python aiogram Groq API (LLM) SQLite systemd

Честно: это MVP, а не проверенный на большом потоке пользователей продукт - план развития говорит о «первых 100-500 пользователях» как о цели, а не факте. Бот генерирует контент, но не публикует его в Instagram автоматически.
