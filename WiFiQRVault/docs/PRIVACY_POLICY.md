# Privacy Policy

This privacy policy applies to the **WiFi QR Vault** app (hereby referred to as "Application") for mobile devices that was created by **MobileWave Dev** (hereby referred to as "Service Provider") as an Ad Supported service. This service is intended for use "AS IS".

---

## What the Application Does

WiFi QR Vault lets you save Wi-Fi network names and passwords, generate a QR code for a saved network so others can connect without typing the password, and scan a Wi-Fi QR code (yours or someone else's) to read or connect to a network. Saved networks can optionally be exported as a PDF file.

---

## Information Collection and Use

**Wi-Fi network data you add.** The network name (SSID), password, security type, an optional group and an optional comment that you enter are stored **only in a local database on your device**. The password is encrypted before being saved, using a key generated and kept in the device's Android Keystore (AES/GCM); this key does not leave the device. This data is not sent to the Service Provider's servers.

**Camera and QR scanning.** If you use the QR scanner, the Application uses your device's camera to read the QR code. Scanning is performed on the device using an on-device barcode-recognition library; the camera preview and scanned codes are not uploaded anywhere by the Application. Camera access is optional - the Application can be installed and used without a camera, and you will only be asked for camera permission when you open the scan screen.

**Wi-Fi and network permissions.** The Application requests access to the current Wi-Fi connection state and to the device's network state, and can change the Wi-Fi configuration on your device. These permissions are used to show information about the network you are connected to and to let the Application add or switch to a Wi-Fi network from a scanned QR code, using standard Android system APIs. The Application does not use these permissions to transmit your Wi-Fi credentials to the Service Provider.

**Storage and PDF export.** On Android versions where the Application requests storage permission, and via the Android system's own file-sharing mechanism on newer versions, the Application can export saved networks (for example, as a PDF with QR codes) to a file that you choose to save or share. This file is created and stored on your device or wherever you choose to send it; the Service Provider does not receive a copy.

**Device information.** As with most apps, the Application and the third-party services described below may automatically collect standard technical information such as your device's IP address, device and OS version, app version, screens visited and time spent in the Application, and the advertising ID of your device.

**Accounts.** The Application does not require you to create an account and does not ask for your name, e-mail or phone number.

## Backups

The Application allows the operating system to include its data in your device's standard Android backup (tied to your Google account), as no custom backup rules exclude it. Wi-Fi passwords stored inside the app database remain encrypted with a key kept in the device's Android Keystore; this key is generally device-specific and is not expected to transfer with a backup restored to a different device, so restored password data may not be usable on a new device. You can disable app backup for the Application in your device's system settings.

You can stop all collection of information by the Application by uninstalling it, which also deletes the local database with your saved networks. You may use the standard uninstall process available as part of your mobile device or via the mobile application marketplace.
